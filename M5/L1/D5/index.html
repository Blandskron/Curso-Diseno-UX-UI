Paleta de Colores Funcional

Esta paleta está diseñada desde principios de arquitectura cognitiva, jerarquía visual y percepción humana. Cada color cumple una función clara y predecible: no decora, comunica.

Primario — Acción Principal

#1F3A8A
Azul profundo asociado a confianza, estabilidad y control. Se utiliza para acciones primarias (CTA), enlaces clave y estados activos. Reduce ansiedad y es culturalmente neutro para interfaces críticas.

Secundario — Soporte

#64748B
Gris azulado de baja activación emocional. Sirve como soporte visual para textos secundarios, bordes y UI pasiva. No compite con la acción principal ni distrae la atención.

Éxito — Confirmación

#16A34A
Verde natural asociado a progreso y resolución correcta. Se usa para feedback positivo, estados completados y confirmaciones. Refuerza sensación de avance sin sobreestimular.

Advertencia — Atención

#F59E0B
Ámbar de alta visibilidad pero menor agresividad que el rojo. Indica riesgo, estados intermedios o decisiones reversibles. Llama la atención sin generar pánico cognitivo.

Error — Acción Crítica

#DC2626
Rojo de alto contraste asociado a peligro y detención. Reservado exclusivamente para errores, bloqueos y acciones destructivas. Su uso limitado mantiene su impacto cognitivo.

Fondo — Espacio Cognitivo

#F8FAFC
Blanco frío con leve matiz azulado. Reduce fatiga visual frente al blanco puro y mejora legibilidad prolongada. Funciona como espacio negativo activo.
